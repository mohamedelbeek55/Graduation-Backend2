Google ID Token — Postman Test Helper

Click the button below to sign in with Google. Your ID token will appear in the box — copy it and paste into Postman.


How to use in Postman:

  1. Sign in with Google above
  2. Copy the token from the box
  3. In Postman: POST http://localhost:3000/api/auth/google
  4. Body → raw → JSON:
    { "idToken": "PASTE_TOKEN_HERE" }
  5. Send — you'll get back your LexaGuide accessToken

Note: Google ID tokens expire after 1 hour. If you get "Invalid Google token", sign in again to get a fresh one.
